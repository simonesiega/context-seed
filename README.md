# ContextSeed

ContextSeed is an early-stage, local-first Agent Skill intended to give coding agents persistent, token-efficient understanding of a codebase while keeping source files authoritative.

> **Status:** This project is currently in development.

The distributable skill will live in [`skills/contextseed/`](skills/contextseed/). See the [roadmap](ROADMAP.md) for the planned development sequence.
